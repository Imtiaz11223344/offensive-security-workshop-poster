# Offensive Security Workshop – Poster Design

This repository contains a Canva-designed poster created for an **Offensive Security Workshop** held at **COMSATS University Islamabad**.

The poster highlights:
- OSCP+ delivered training
- Learning outcomes
- Training details
- Prerequisites
- Contact information



## 🎨 Purpose
This design project was created as part of my **Bachelor of Software Engineering** portfolio to showcase:
- Graphic design skills (Canva)
- Creativity in cybersecurity-themed poster creation
- Visual communication and layout design
